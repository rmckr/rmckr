## About

I've been programming for quite a while, mostly because I enjoy it.

Most of the things I build start with a problem I want to solve, an idea I want to try, or simply something I want to understand better. That usually means there's a bit of everything on my GitHub.

I enjoy working with frontend applications and the occasional backend service or database, but I'm not particularly interested in staying in one corner of software development.
